# Développement Web 1

**Enseignante : Amani Selmi, PhD-Engineer**

11 séances de 3 h. Cours en français, termes techniques en anglais.

Dans ce cours, vous allez construire une vraie application web, de la première page HTML jusqu'à la base de données, **sans framework**. L'objectif n'est pas de connaître beaucoup d'outils. L'objectif est de comprendre comment le Web fonctionne vraiment, pour pouvoir ensuite apprendre n'importe quel framework rapidement.

## Stack

HTML · CSS · JavaScript · PHP 8 · MySQL (PDO) · Git
