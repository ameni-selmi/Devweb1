# Semaine 6 : MySQL et PDO

## À la fin de cette semaine, vous savez

* expliquer ce qu'une base de données apporte par rapport à un fichier ou une session ;
* créer une base à partir d'un script SQL ;
* vous connecter à MySQL avec PDO, correctement configuré ;
* écrire des requêtes préparées, et montrer pourquoi elles empêchent l'injection SQL ;
* utiliser un JOIN et les contraintes de la base.
