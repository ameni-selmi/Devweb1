## Signaux d'alerte à noter

* Un seul membre a commité : en parler **maintenant**, pas en S11.
* La mécanique centrale n'a pas commencé : la découper avec eux en une version minimale pour S09.
* Framework, bibliothèque CSS ou template interdit : le signaler tout de suite.
* Code visiblement généré sans être compris (structure très différente du cours, classes inutiles) : poser une question sur une ligne au hasard.
