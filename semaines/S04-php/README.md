# Semaine 4 : PHP et le serveur

## À la fin de cette semaine, vous savez

* lancer un serveur PHP et expliquer ce qu'il fait d'une requête ;
* générer du HTML à partir de données, avec des boucles et des `require` ;
* traiter un formulaire : `$_GET`, `$_POST`, validation serveur, réaffichage ;
* expliquer la faille XSS et l'éviter avec `e()`.
